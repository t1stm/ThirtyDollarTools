The Lato fonts are sourced from Google Fonts.

The Twemoji.Mozilla.ttf file is from the [mozilla/twemoji-colr](https://github.com/mozilla/twemoji-colr) repo.
`lucide.ttf` is the icon font from [Lucide](https://lucide.dev), taken from the `lucide-static`
npm package, version 1.55.0 (`font/lucide.ttf`). ISC licence (some icons MIT, from Feather); see
`LICENSE-lucide.txt`. The codepoints the UI uses are in `Sundex.Components/Icons.cs`, read from the
same version's `font/info.json`.
