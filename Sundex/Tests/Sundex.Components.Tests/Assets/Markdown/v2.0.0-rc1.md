### Performance Enhancements

The library that the Converter uses for exporting the raw audio got an additional working mode. This one is called Incremental Audio Export.

The core idea is that you take in an already exported sequence, make changes to it, and then re-render it again. This normally would've costed an entire re-render of the whole sequence. This mode first checks what was changed, subtracts the sound at the location the change was made, and applies the new sound. 

This is heavily used in the new version of the Visualizer that will be documented below.

### Bug Fixes

I've also fixed many bugs that were plaguing accurate exports compared to the TDW with the most important being the panning calculation method. Currently, sequences exported from the TDW match one-to-one with the ones from the Converter, from the short tests I've made and the limited library of sequences I have. The export should be a lot more faithful to the sound the TDW produces.

# Improvements to the Custom TDWex Format

Most of the defining features of the TDWex format got actually added to the TDW. Panning and individual sound cutting are now a core feature of the Website. To continue the novelty aspect of the TDWex format, I have added a new sound modifier: 

### The Offset modifier

This modifier basically offsets the start of the sound by given seconds. 

`sound@0>0.33` has its start sample offsetted by 0.33 seconds.

It should be a great addition to the already big sound manipulation stack that the TDW has, and bring another level to create complex covers of songs.

# Improvements to the Visualizer

This has been the main focus of work since the last release. The graphics engine that the Visualizer uses has been overhauled from the ground up with components and batch rendering in mind. What this means for you is that the Visualizer should use less power when running it and be a lot smoother when playing or working with it.

As for the look, the Visualizer got a Home Screen, and a simple playback controller bar on the bottom of the window. This one allows seeking back and forth, restarting and play-pausing the sequence without having to remember each shortcut manually.
