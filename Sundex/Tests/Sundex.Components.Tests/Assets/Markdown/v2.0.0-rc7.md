## Changes after RC6

This one took a while. Two months of work, almost all of it on the Editor.

The biggest addition is the Faithful track. It works like the website itself: a grid of tiles you place one after another, which gets exported exactly as you wrote it. You can import an existing cover as one and keep working on it in the Editor, and a Piano Roll import will suggest one when the sequence doesn't fit a piano roll well.

Piano Roll tracks got long notes: drag a note's border to make it longer, and the automation markers shape it. Since a TDW cut silences a sound everywhere, two long notes on the same instrument used to cut each other off. The new Auto resume option in the Project panel puts the cut note back automatically. Notes also got an instrument-wide sound offset, and you can edit the automation of several notes at once.

There are also wave reference tracks now, so you can drop a WAV stem next to your tracks and write against the original song.

The instrument builder was redesigned, with a sound picker you can search, sound previews on right-click and a preview of the whole instrument on the play key.

The whole Editor got a visual pass too. Notes and clips are shaded now, a note gets darker the quieter it is, and automation is drawn as volume bands with a marker where each keyframe starts. Clips show a small preview of what's inside them. The top bar, the import dialog, the Add a track dialog and the file, export, instrument and unsaved-changes dialogs were all redesigned. It also fits in a 1080x720 window now, and it got a good bit faster on big projects.

Plus a pile of smaller things: picking a track's colour (for several tracks at once too), dragging a selection of clips or tracks as a group, clicking a note to pick its instrument, cutting the hovered instrument with X in a Faithful track, and Alt+Enter (Cmd+Shift+F on macOS) for fullscreen, except on Wayland.

Text in the Visualizer and the Editor is now rendered with Slug instead of MSDF, so it should look a lot crisper. The Visualizer's player bar was restyled to match the Home screen, the controls text was replaced with a shortcut sheet, there's a scroll bar down the right edge, and you can pick the resampler in the settings.

There are also install scripts for Linux and Windows that add menu shortcuts for the Visualizer and the Editor and let you open sequences in the Visualizer and projects in the Editor straight from your file manager.

The project also has a website now, with downloads for every platform: https://t1stm.github.io/ThirtyDollarTools/
